# severally plugin

Ask coding agents for independent opinions, returned separately. The lead checks the grounds and records its decision.

For requirements, installation, the first question and known protection limits, see the
[English guide](https://github.com/coz-a/severally/blob/main/README.md) or
[日本語ガイド](https://github.com/coz-a/severally/blob/main/README.ja.md).

This directory contains the bundled MCP server and generated host-specific skills. Edit the source and skill
templates at the repository root, then run `npm run build`.
